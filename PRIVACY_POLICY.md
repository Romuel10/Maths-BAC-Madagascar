# Confidentialité — Maths BAC Madagascar 2.2.0

L’application ne demande pas de compte et ne transmet pas les expressions, notes, réponses ou résultats à un serveur de calcul. Elle ne contient ni publicité ni outil de suivi publicitaire.

Les préférences, brouillons, favoris, notes et résultats d’entraînement sont stockés localement sur l’appareil. L’export est déclenché par l’utilisateur ; sur Android, le menu de partage lui permet de choisir la destination. La restauration remplace les données v2 après confirmation.

La version web télécharge les fichiers de l’application et les conserve pour fonctionner hors connexion. L’hébergeur peut recevoir les informations techniques habituelles d’une requête web. Les liens vers des annales et programmes ouvrent des sites externes dont les règles de confidentialité s’appliquent.

Supprimer les données de l’application ou les données du site efface les données locales. Les copies exportées restent à supprimer dans leur destination respective.
