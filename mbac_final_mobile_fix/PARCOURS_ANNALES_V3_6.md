# V3.6 — Parcours annales 2022–2023

Cette version transforme la bibliothèque d’annales en espace de travail pédagogique.

## Principe de fiabilité

L’application distingue désormais :

- **Énoncé référencé** : l’année et la série apparaissent dans l’archive EDUCMAD/ACCESMAD consultée.
- **Énoncé non confirmé** : une correction ou un catalogue existe, mais l’énoncé n’a pas été retrouvé dans la section d’énoncés utilisée pour la vérification.
- **Corrigé du problème** : seul le corrigé du problème est explicitement référencé.
- **Corrigé partiel** : certains exercices/problèmes sont référencés, sans prétendre couvrir tout le sujet.
- **Corrigé non confirmé** : aucune correction de l’année n’est présentée comme disponible dans l’archive consultée.

## Couverture 2022–2023 intégrée

- Série D 2023 : énoncé référencé ; corrigé du problème référencé.
- Série D 2022 : énoncé référencé ; corrigé du problème référencé.
- Série C 2023 : énoncé référencé ; corrigé non confirmé dans la section consultée.
- Série C 2022 : énoncé référencé ; corrigé non confirmé dans la section consultée.
- Série A 2022 : énoncé référencé ; corrigés partiels référencés.
- Série A 2023 : corrigés partiels référencés, mais énoncé 2023 non confirmé dans la section d’énoncés consultée.

## Espace de travail

Chaque parcours comprend :

1. un accès à la source ;
2. une procédure de résolution en cinq étapes ;
3. une checklist avant validation d’une réponse ;
4. un champ « question en cours » ;
5. un journal d’erreurs sauvegardé localement ;
6. un accès à l’atelier de résolution pédagogique.

Les textes complets des sujets externes ne sont pas recopiés automatiquement dans le code. Cette décision limite les erreurs d’OCR et évite qu’une source non vérifiée soit présentée comme officielle.
